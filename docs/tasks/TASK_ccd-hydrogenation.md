# TASK: CCD参照構造による水素付加

> X線結晶構造解析由来の入力(通常のPDB/mmCIF)には水素座標が含まれないことが多く、ProteinDFでのDFT計算には全原子座標が必要になる。ユーザーから「X線構造など水素情報がないデータに対して、CCDを参照して水素を付加する機能が欲しい」との要望があった。詳細設計・スコープ判断(対象コンポーネント範囲、回転可能水素の扱い、プロトン化状態の扱い)はユーザーとの対話で確定済み。詳細は`RUST_PORT_SPEC.md` §3.16を参照。

## 背景

`RUST_PORT_SPEC.md` §3.16に全設計を記載済み。要点:

- 既存の`modeling.rs`(`get_ACE`/`get_NME`、Phase 6)が確立した「参照構造を`Superposer`で実構造の重原子に重ね合わせ、欠けている原子を転写する」パターンを一般化する。
- CCDの水素には2種類あり、扱いが異なる:
  1. 単一コンポーネント内で幾何が完結する水素(側鎖OH/SH/NH3+、リガンド全水素、CA-H): CCD理想配座の剛体重ね合わせで対応(PR#38)。
  2. 主鎖アミドN-H: CCD遊離アミノ酸エントリのN末端型ジオメトリとは異なるため、独立した幾何計算が必要(PR#39)。
- スコープ: 任意のCCDコンポーネント対応(リガンド含む)、回転可能水素はCCD理想配座をそのまま採用(局所最適化なし)、プロトン化状態は中性・標準タウトマー固定のみ。

**着手前に`RUST_PORT_SPEC.md` §3.16を必ず精読すること。** 本TASKファイルは実行チェックリストであり、設計判断の根拠・背景は§3.16側にある。

### 実バグ(要修正)

1. **`Superposer`の入力が共線/縮退している場合の検証が無く、無効な回転行列が無言で返る**(`hydrogenation.rs:154`、根本原因は`superposer.rs`の`calc_rotation_matrix`、257行目付近)。
   - `calc_rotation_matrix`の行正規化ループは`if w > 0.0`のときだけ正規化し、`w`が0(またはほぼ0)の行はそのまま(ゼロベクトルのまま)残す。フィットに使う重原子が共線または近共線の場合、相関行列のランクが落ちてこの経路に入りうるが、`Superposer::new`はこれを検出せず`Ok`を返す。
   - **再現手順**: `MIN_SUPERPOSE_HEAVY_ATOMS`(3点)ちょうど、かつ3点がほぼ一直線に並ぶような`fit_heavy_atoms`を明示指定(または実構造がたまたまそうなる場合)して`add_hydrogens_to_component_in_place_with_options`を呼ぶ。エラーにならず、化学的に無意味な座標の水素が追加される。
   - これはdocコメント「3点あれば信頼性高く重ね合わせられる」(`MIN_SUPERPOSE_HEAVY_ATOMS`の説明)という主張と矛盾する。
2. **`fit_heavy_atoms`を明示指定すると、末端残基でのカルボニルO歪み対策が完全にバイパスされる**(`hydrogenation.rs:118`)。
   - 107〜111行目のコメントで説明されている重要な保護ロジック(`is_internal_peptide_residue && ccd_atom.name == "O"`のスキップ)は、`options.fit_heavy_atoms`が`Some`の場合の`else if`分岐にあり、`fit_heavy_atoms`指定時は一切評価されない。
   - **再現手順**: 鎖内(非末端)残基に対し`fit_heavy_atoms: Some(&["N","CA","C","O"])`のように"自然に見える"リストを明示指定して呼び出すと、コメントが説明する歪み(psi角に依存した約170°のずれ)がそのまま発生する。
3. **末端判定ヒューリスティックがタンパク質の原子名(OXT/N/CA/C)にハードコードされており、`RUST_PORT_SPEC.md` §3.16が要求する「固定リストではない汎用マッチング」方針、および核酸・リガンドを対象に含めるスコープと整合しない**(`hydrogenation.rs:107`)。
   - 核酸残基や、遊離カルボキシラートをモデル化していないCCDテンプレート(=`OXT`原子が無い)では、この保護が一切効かない。該当する残基種では常に対策なしの状態になり、実バグ2と同種の歪みが発生しうる。

### 修正方針

### 実バグ(要修正、最重要)

1. **水素を追加するループが、追加しようとする水素自身の名前が`component`に無いことだけを確認しており、その水素が結合している重原子(親)が`component`に実在するかを一切確認していない。** これは初回実装(PR#38 1回目)から存在していた問題で、過去3回のレビューでも見逃していた。(`hydrogenation.rs`、水素転写ループ、約198〜226行目)
   - **再現手順**: 組み込みALAテンプレートは`N`に対し`H`・`H2`の2つの水素を持つ(遊離アミノ酸の自由アミンを表現するため)。鎖内(非末端)の通常のALA残基(主鎖アミドNは水素1個のみが化学的に正しい)に対し`add_hydrogens_to_component`を呼ぶと、`component`は`H2`という名前の原子を持たないため、`H2`が無条件に追加されてしまう(Nの過剰プロトン化、化学的に誤り)。同様に、C末端の`OXT`が無い鎖内残基でも、`OXT`に結合する`HXT`が(`OXT`自体は追加されないまま)無条件に追加され、対応する重原子を持たない水素が生成される。
   - **修正方針**: 水素を追加する前に、`template.bonds`からその水素が結合している重原子(親)を特定し、その親が`component`に実在することを確認すること(親が無ければスキップする)。これは`OXT`→`HXT`のようなケースを正しく解決する。**ただし、これだけでは`N`→`H2`のケース(親`N`は常に実在する)は解決しない。** 既存の内部/末端判定ロジック(現在の実装での呼称を確認して使うこと)を使い、鎖内残基と判定された場合は、主鎖`N`に結合する2つ目以降のアミン水素(`H2`、テンプレートに存在すれば`H3`も)を、親の存在有無に関わらずスキップすること。

### スコープ変更(ユーザー承認済み、2026-09-24)

核酸のリン酸基まわりの歪み検知(`detect_distorted_terminal_atoms`の`OP3`/`OP1`/`OP2`/`O5'`関連ロジック)が、3回のレビューラウンド(2・3・4回目)にわたり同種の誤判定(架橋酸素の誤除外→非架橋酸素`OP1`/`OP2`の誤除外)を繰り返しており、かつ核酸の実データ・合成テストフィクスチャが一切用意されていない。ユーザー判断により、**本PRでは`detect_distorted_terminal_atoms`をタンパク質(`OXT`)専用に縮小すること。**

- `is_known_terminal_capping_heavy_atom`を`matches!(name, "OXT")`のみに戻す(`"OP3"`を削除)。
- 関連するdocコメント(`detect_distorted_terminal_atoms`本体、`HydrogenationOptions::auto_exclude_distorted_atoms`等)から核酸/リン酸基への言及を削除し、「本ガードはタンパク質の主鎖カルボニルOのみを対象とする」ことを明記する。核酸対応は既知の限界として`hydrogenation.rs`冒頭の`# Known Limitations`セクションに追記すること。
- 核酸関連のテスト(`test_hydrogenation_nucleic_acid_*`等、O5'保持を検証しようとしていたもの)は、本スコープ変更に伴い削除または「対応外であることを示す」形に変更すること。

### 検討したが対応不要と判断した指摘(Claude自身で検証済み)
