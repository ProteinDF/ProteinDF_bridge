# TASK: 挿入コード（insertion code）修正の実データによる追加検証

> `fix/residue-insertion-code`（`RUST_PORT_SPEC.md` 9章参照）で挿入コード無視バグを修正したが、追加した回帰テストは全て手書きの合成PDB/mmCIF文字列によるものであり、実際の挿入コード付き残基を含む実ファイルでの検証がまだ行われていない。本タスクはこれを補う。

## ブランチ運用(MUST)

- `develop` から `test/residue-insertion-code-real-data` を作成して作業する。
- **`develop` へは自分でマージしない。** 実装・テスト・`cargo clippy`/`cargo fmt`確認が終わったら、ブランチ名と完了内容をユーザー経由でClaudeに報告し、レビュー承認(または修正依頼)を待つこと。
- 依存関係: `fix/residue-insertion-code`がマージ済みであることを前提にする（マージ済み: `develop`コミット`4f33af0`）。

## 対象

1. **実際に挿入コードを含むPDB/mmCIFファイルの取得と検証**:
   - wwPDB (RCSB PDB, https://www.rcsb.org、パブリックドメイン) から、挿入コード付き残基を実際に含むエントリを取得する。
   - **値を記憶や推測で選ばないこと。** 「このPDB IDには挿入コードがあるはず」という記憶や推測だけで候補を決めず、実際にダウンロードしたファイルの中身（PDB形式ならATOMレコードのカラム27、mmCIF形式なら`_atom_site.pdbx_PDB_ins_code`）を検査し、空白/`.`/`?`以外の値が実際に存在することを確認してから採用すること。
   - 候補が見つからない、または挿入コードの有無に自信が持てない場合は、実装を止めてユーザー経由でClaudeに相談すること。
   - `scripts/build_ccd_bond_templates.py`が実際にRCSBからデータを取得している既存の前例を参考にしてよい（取得元・ライセンスの扱いが同様のため）。
2. **フィクスチャの追加**: 取得したファイル（PDB形式・mmCIF形式のいずれか、または両方）を`rust/crates/proteindf-bridge/tests/data/`に追加する。ファイルサイズが大きい場合は、挿入コード付き残基を含む範囲を中心に、テストに必要な部分だけを抽出した縮小版を作成してよい（その場合、元のPDB IDと抽出方法をコメントまたはコミットメッセージに明記すること）。
3. **実データ回帰テストの追加**:
   - `tests/test_pdb.rs`（PDB形式を使う場合）および/または`tests/test_mmcif.rs`（mmCIF形式を使う場合）に、上記フィクスチャを読み込み、`get_atomgroup()`の結果に挿入コード付き残基が同一`res_seq`の他の残基とマージされず正しく分離されていることを検証するテストを追加する。
   - `fix/residue-insertion-code`で追加した合成データテスト（`test_pdb_insertion_code_residues`等）と同様の検証観点（残基の分離・原子数・残基名）を、実データに対して行うこと。
   - SSBOND/`_struct_conn`結合が絡む挿入コード付き残基が実ファイル中に存在する場合は、その結合が正しく解決されることも検証すること（存在しない場合はこの観点は省略してよい）。

## 完了の定義(Definition of Done)

1. 実際に挿入コードを含むことを確認済みの実PDB/mmCIFファイル（または抽出した縮小版）が`tests/data/`に追加されていること。
2. そのファイルを読み込む回帰テストが追加され、挿入コード付き残基が正しく分離保持されることを検証していること。
3. 既存テストが全て引き続きパスすること。
4. `cargo clippy --workspace --all-targets -- -D warnings` / `cargo fmt --check` を通すこと。
5. `RUST_PORT_SPEC.md` 9章の該当項目（「既知の制約」の記述）を更新し、実データ検証が完了したことを追記すること。

## スコープ外

- 挿入コード処理のロジック自体の変更（`fix/residue-insertion-code`で実装済み。本タスクはテスト追加のみが対象）。

## やってはいけないこと

- 既存Pythonコード(`proteindf_bridge/`)は変更しない。
- **挿入コードを含むと確認していないファイルを「含んでいるはず」として使わない。** 必ずファイルの中身を検査して確認すること。
