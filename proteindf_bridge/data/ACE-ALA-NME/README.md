# ACE-ALA-NME 構造データ

- Gaussianにてrb3lyp/6-31Gで構造最適化

trans1:
- ALA:-C=O と ACE:-C=O が逆方向
- ALA:CA-H と ALA:-C=O が逆方向

trans2:
- ALA:-C=O と ACE:-C=O が逆方向
- ALA:CA-H と ALA:-C=O が同方向

cis1:
- ALA:-C=O と ACE:-C=O が同方向
- ALA:CA-H と ALA:-C=O が逆方向

cis2:
- ALA:-C=O と ACE:-C=O が同方向
- ALA:CA-H と ALA:-C=O が同方向

## Gaussianの出力ファイルについて

構造最適化の出力ファイル(`*.out`)は、計算機名・ユーザー名・パスなどの個人情報を含むため、リポジトリには置いていない(2026-10-05に削除)。必要な場合は、同じディレクトリの入力ファイル(`*.gjf`)から再計算できる。
